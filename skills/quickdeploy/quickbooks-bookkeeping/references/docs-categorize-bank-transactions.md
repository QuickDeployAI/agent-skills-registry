## Review the For Review tab

1. Open **Transactions → Bank transactions** and select the account.
2. Work newest-first through the *For Review* tab.
3. For each row: accept QuickBooks' suggested category when it matches the vendor's history; otherwise pick the correct expense/income account.
4. Use **Match** (not Add) when the transaction corresponds to an existing invoice, bill, or transfer — adding creates duplicates.
5. Split transactions that cover multiple categories (button: *Split*).

## Rules of thumb

- Transfers between own accounts are matched as transfers, never income.
- Owner draws/contributions go to equity accounts, not expenses.
- When unsure, park the row in *Ask My Accountant* rather than guessing.
