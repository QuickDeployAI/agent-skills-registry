# stripe command reference

Generated by cli-2-agent-skills from a captured help dump (stripe 1.21.8).

## Safe commands (read-only or reversible)

- `stripe payment_intents list`
- `stripe charges retrieve`
- `stripe customers list`
- `stripe subscriptions list`
- `stripe balance_transactions list`

## Destructive commands — explicit confirmation required

Summarize the exact objects and amounts affected and wait for the user
to confirm before running any of these:

- `stripe refunds create`
- `stripe subscriptions cancel`

## Command help

### `stripe balance_transactions list`

```text
Usage:
  stripe balance_transactions list [--limit <n>] [--payout <po_id>] [flags]

List balance transactions (charges, refunds, fees, payouts) for reconciliation.
```

### `stripe charges retrieve`

```text
Usage:
  stripe charges retrieve <charge_id> [flags]

Retrieve a single charge by ID (ch_...).
```

### `stripe customers list`

```text
Usage:
  stripe customers list [--limit <n>] [--email <email>] [flags]

List customers, most recent first.
```

### `stripe payment_intents list`

```text
Usage:
  stripe payment_intents list [--limit <n>] [--customer <cus_id>] [flags]

List payment intents, most recent first.

Flags:
  --limit          Number of objects to return (1-100, default 10)
  --customer       Only return payment intents for this customer
  --starting-after Pagination cursor
```

### `stripe refunds create` (destructive)

```text
Usage:
  stripe refunds create --charge <charge_id> [--amount <cents>] [flags]

Create a refund against a captured charge. Omit --amount for a full refund.
```

### `stripe subscriptions cancel` (destructive)

```text
Usage:
  stripe subscriptions cancel <subscription_id> [flags]

Cancel a subscription immediately. Use `subscriptions update --cancel-at-period-end true` to cancel at period end instead.
```

### `stripe subscriptions list`

```text
Usage:
  stripe subscriptions list [--customer <cus_id>] [--status <status>] [flags]

List subscriptions, optionally filtered by customer or status.
```
